# Test materials

A shared place in this repository for materials used to test or evaluate approaches related to agent identity and ARIA: test cases, protocols, fixtures and results.

## What this folder is

- Input documents for the group. They are not deliverables of the group.
- Sharing a file here does not imply endorsement by the group or by ARIA.
- ARIA is evaluated against its own specification: <https://aria.bar/spec>

## One folder per project

Each project has its own folder inside `test-materials/`, named after the project, for example `test-materials/hiring-receiver-test/`. The participant who proposes a project creates its folder and manages the files in it. Anyone can read, comment and discuss, but each folder is edited by its own authors.

Each project folder starts with a short `README.md` that states:

- Title, authors and affiliation
- Date and version
- What it tests
- Whether it relates to ARIA, and how
- Status (draft, for discussion)

## Who can add files

Participants of the group, through a pull request.

## Implementations

If a project depends on an implementation, the author presents it at a group meeting so that everyone knows what it is before feedback is requested.

## Please do not add

Personal data, keys or credentials, or anything that cannot be shared publicly.
